# تحليل الطلب على النقل التشاركي في مكة خلال رمضان

🌐 [English](README.md) | **العربية**

🏆 **المركز الأول — معسكر البيانات، جامعة أم القرى**

مشروع جماعي يستكشف أنماط الطلب على النقل التشاركي خلال رمضان في مكة المكرمة، ويقترح إعادة توزيع استباقية للأسطول لمواءمة العرض مع الطلب.

> **شفافية البيانات:** البيانات المستخدمة مُحاكاة إحصائياً. بدأ المشروع من بيانات عامة لرحلات Uber وLyft في بوسطن، ثم أضيفت طبقة محاكاة لمواقع في مكة وأيام رمضان وفترات الصلاة والطقس. النتائج المذكورة هنا ناتجة عن هذه المحاكاة، ولا تمثل قياسات تشغيلية حقيقية للنقل في مكة.

## المشكلة

قد يتغير الطلب على النقل بشكل ملحوظ حول أوقات الصلاة والتجمعات. وقد لا تستجيب خطط توزيع الأسطول الثابتة لهذه التغيرات بسرعة، مما يسبب فجوات مؤقتة بين عدد المركبات المتاحة والطلب على الرحلات.

## أهداف المشروع

- استكشاف أنماط الطلب عبر مواقع وفترات زمنية مُحاكاة في مكة.
- دراسة ارتباط بعض الميزات الزمنية المُهندسة بالطلب.
- بناء مسار لمعالجة البيانات وتجربة أسلوب للتنبؤ بالطلب.
- اقتراح طرق لإعادة توزيع الأسطول قبل فترات الذروة المتوقعة.

## مراحل العمل على البيانات

| المرحلة | العمل |
|---|---|
| دمج البيانات | دمج سجلات الرحلات مع بيانات الطقس حسب الطابع الزمني |
| محاكاة المواقع | ربط المواقع الأصلية بمعالم مختارة في مكة |
| هندسة الميزات | إنشاء ميزات مثل `ramadan_day` و`prayer_period` و`is_last_ten` و`dist_to_haram` |
| تنظيف البيانات | معالجة القيم المفقودة والمكررة والقيم المتطرفة للأسعار |
| التحليل والنمذجة | استكشاف الأنماط وتجربة التنبؤ بالطلب |

تحتوي البيانات المُجهزة والمحاكاة على **637,976 سجلاً**.

## النتائج المعلنة

الأرقام التالية ناتجة عن البيانات المُحاكاة وافتراضاتها:

| المؤشر | القيمة المعلنة |
|---|---:|
| متوسط الطلب | 26,582 رحلة/ساعة |
| سعة الأسطول المفترضة | 27,000 مركبة |
| ذروة الطلب | 29,872 رحلة/ساعة |
| الفجوة المحسوبة عند الذروة | 2,872 رحلة (10.6%) |
| معامل R² لنموذج Random Forest | 0.94 |

**قيد مهم:** تم توليد ميزات مثل فترات الصلاة وأيام رمضان والطقس ضمن المحاكاة. لذلك فإن أهميتها في النموذج تعكس افتراضات المحاكاة، ولا ينبغي اعتبارها دليلاً على واقع النقل في مكة. يتطلب التحقق من النتائج استخدام بيانات تشغيلية حقيقية.

## التوصيات التي استكشفها المشروع

- دراسة نقل جزء من سعة الأسطول من المناطق الأقل طلباً إلى المناطق المتوقع ارتفاع الطلب فيها.
- تضمين السياق الزمني المناسب في تخطيط الطلب.
- تقييم إعادة توزيع الأسطول كخيار بديل عن زيادة عدد المركبات.

هذه توصيات مبنية على سيناريو مُحاكى وليست تعليمات تشغيلية فعلية.

## مساهمة الفريق والشفافية حول استخدام الذكاء الاصطناعي

عمل الفريق على تجهيز البيانات باستخدام Python، بما يشمل دمج الرحلات مع الطقس، ومحاكاة المواقع، وهندسة الميزات، والتنظيف، وإعداد العرض التقديمي. واستُخدمت مساعدة الذكاء الاصطناعي في أجزاء من التحليل الاستكشافي والتنبؤ باستخدام Random Forest والعمل على الداشبورد التفاعلي بعد تجهيز البيانات.

## الأدوات المستخدمة

- **Python وPandas وNumPy** — معالجة البيانات وهندسة الميزات
- **Matplotlib وSeaborn** — التحليل الاستكشافي والتصور
- **Scikit-learn** — نمذجة Random Forest

## طريقة التشغيل

1. استنسخ المستودع:
   ```bash
   git clone "https://github.com/by-shooq/makkah-ramadan-rides..git"
   cd "makkah-ramadan-rides."
   ```

2. ثبّت المكتبات:
   ```bash
   pip install -r requirements.txt
   ```

3. حمّل ملفات CSV الموضحة في [data/README.md](data/README.md) وضعها داخل مجلد `data/`.

4. شغّل سكربت هندسة الميزات من المجلد الرئيسي:
   ```bash
   python feature_engineering.py
   ```
